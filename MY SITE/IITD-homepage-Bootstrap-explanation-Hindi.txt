नमस्ते। इस audio में मैं बताऊँगा कि मेरे IIT दिल्ली learning project के home page में Bootstrap कहाँ इस्तेमाल हुआ और उससे browser पर क्या असर दिखता है। Website में Bootstrap version पाँच दशमलव तीन दशमलव आठ की local CSS file है। Index dot html के head section में assets folder की Bootstrap stylesheet को link किया गया है। उसके बाद custom styles dot css link होती है। Bootstrap सामान्य responsive layout और components देता है; हमारी CSS उनको website के colors और design के अनुसार customize करती है।

सबसे पहले container class। यह content को एक readable central area में रखती है। Project की custom CSS इसकी maximum width को लगभग 1180 pixels करती है। Wide screen पर text और cards बहुत दूर तक नहीं फैलते, जबकि Bootstrap container किनारों की spacing देता है।

Container के अंदर row class grid row बनाती है। Row के अंदर col classes तय करती हैं कि हर item कितनी जगह लेगा। उदाहरण के लिए institute statistics में col sm six और col lg four है। Bootstrap के responsive breakpoints पर छोटी screen में हर card लगभग आधी row लेता है, और बड़ी screen पर हर card एक तिहाई row लेता है। इसका मतलब phone पर दो cards और desktop पर तीन cards एक row में हो सकते हैं।

Discover section के cards में col sm six और col xl three है। Small screen से दो cards एक row में आ सकते हैं, और extra large screen पर तीन-column width के कारण चार cards एक row में दिखते हैं। Research cards में col md six और col xl four है: मध्यम screen से दो cards और बहुत चौड़ी screen पर तीन cards। Footer के col md six और col lg three से mobile पर चौड़े दो columns और desktop पर चार footer columns बनते हैं। Campus video row में col lg seven और col lg five इस्तेमाल है। बड़े screen पर video को सात हिस्से और उसके विवरण को पाँच हिस्से की चौड़ाई मिलती है।

Bootstrap की g three या g four classes row और columns के बीच gutters बनाती हैं। Mt three और mt four ऊपर margin जोड़ते हैं। H one hundred card को parent column की पूरी ऊँचाई लेने देते हैं, जिससे साथ के cards नीचे से बराबर दिखते हैं। Align items center video और उसके पाठ को vertically align करता है। ये spacing और alignment utilities बार-बार custom code लिखने की ज़रूरत घटाती हैं।

Card component कई जगह है। Card image top तस्वीर रखता है, card body में title और description आती है, card title heading को card के अनुरूप बनाता है। Bootstrap card की basic surface देता है। Custom CSS border radius, shadow, image height और hover movement जोड़ती है। इसलिए card class Bootstrap की है, लेकिन उसका अंतिम look हमारे अपने CSS rules से तैयार हुआ है। Badge soft custom class है; mt three Bootstrap utility है। Btn Bootstrap button base देता है, और btn soft project की अपनी style जोड़ता है।

Navbar में navbar class Bootstrap से है, पर इस project का nav layout मुख्यतः custom CSS से flex, gaps और wrapping द्वारा बनाया गया है। Explore menu HTML details और summary से चलता है, Bootstrap dropdown component नहीं है। Search form के input और button को भी custom CSS style करती है। Visually hidden class Bootstrap की accessibility utility है; label स्क्रीन reader के लिए मौजूद रहता है, जबकि स्क्रीन पर छिपा रहता है। Text secondary और small जैसी classes muted छोटा text दिखाती हैं।

एक ज़रूरी बात: इस homepage में Bootstrap की CSS file है, लेकिन Bootstrap JavaScript bundle नहीं है। इसलिए carousel Bootstrap carousel plugin नहीं है। वह custom CSS keyframes, radio inputs और labels से बना है। Menu भी native HTML details से चलता है। इसीलिए यहाँ Bootstrap component classes उपयोग होने के बावजूद JavaScript की ज़रूरत नहीं पड़ती।

Bootstrap CSS local assets folder में होने से layout और Bootstrap styles लोड करने के लिए internet connection आवश्यक नहीं। Images और campus MP4 भी project folder में local हैं। Bootstrap responsive breakpoints, container, grid, gutters, cards, buttons और utilities की नींव देता है। Custom CSS colors, typography, shadows, animations और specific visual behavior देती है। दोनों मिलकर एक mobile-friendly homepage बनाते हैं, जिसमें desktop पर cards कई columns में और phone पर कम columns में व्यवस्थित होते हैं। धन्यवाद।
