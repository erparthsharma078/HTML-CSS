नमस्ते। इस प्रस्तुति में मैं IIT दिल्ली learning project के फ्रंट पेज की styles dot css फ़ाइल समझाऊँगा। हर CSS नियम का उद्देश्य और स्क्रीन पर उसका असर बताऊँगा। यह stylesheet पूरी वेबसाइट में साझा है, इसलिए इसमें दूसरी pages के लिए भी कई नियम हैं। यहाँ मैं उन्हीं नियमों पर ध्यान दूँगा जो home page पर लागू होते हैं।

फ़ाइल की शुरुआत root selector से होती है। यहाँ ink, navy, pink, blue, mint और shadow जैसे custom properties रखे गए हैं। उदाहरण के लिए var open bracket dash navy close bracket लिखकर वही navy रंग heading, link या button में बार-बार इस्तेमाल हो सकता है। इससे पूरे design की रंग योजना एक जगह से बदलना आसान होता है। Root में कुछ variables बाद में फिर परिभाषित हैं; CSS cascade में उसी priority और selector वाले बाद के नियम पहले को बदल सकते हैं। इसलिए stylesheet पढ़ते समय केवल पहली परिभाषा नहीं, बाद के overrides भी देखना चाहिए।

Star box sizing border box rule सभी elements के width और height की गणना को सरल करता है। Html selector में smooth scrolling है, इसलिए किसी section link पर जाने पर scroll अचानक jump करने के बजाय धीरे चलता है। Body में margin zero, linear या radial gradient background, text color और system font है। Font की 16 pixel base size और line height 1.65 पढ़ने की जगह बढ़ाती है। Img और video पर max width 100 percent है, इसलिए media अपने container से बाहर नहीं निकलती।

Container को maximum width 1180 pixels दिया गया है। इससे चौड़ी screen पर content अनावश्यक रूप से फैला नहीं रहता। Topline को padding, हल्का background और छोटा font दिया गया है। Header sticky position पर है और top zero है। Scroll करते समय वह ऊपर बना रहता है। Z index ten उसे बाकी page content के सामने रखता है। हल्का transparent background, नीचे की border और backdrop filter blur से header साफ़ परत जैसा दिखता है।

Navbar के लिए display flex, gap, padding और flex wrap हैं। इससे logo, navigation, search और official link एक row में समा सकते हैं और जगह कम होने पर अगली line में जा सकते हैं। Navbar brand भी flex है, इसलिए logo और institute name एक साथ align होते हैं। Nav links में padding, गोल border radius, रंग और font weight है। Hover पर हल्का background और थोड़ा ऊपर उठने का transform दिखता है। Search input और button की अपनी CSS है: गोल border, flexible width, focus outline और hover color से search box साफ़ दिखाई देता है।

Hero section carousel का बड़ा banner है। उसकी position relative है, min-height banner को ऊँचाई देता है और overflow hidden किनारों से बाहर जाती चीज़ छिपाता है। छह hero slides absolute position और inset zero से एक ही जगह पर एक-दूसरे के ऊपर रखी जाती हैं। हर slide की image width और height 100 percent है और object-fit cover है। इससे तस्वीर पूरी जगह भरती है और उसका अनुपात नहीं बिगड़ता; ज़रूरत पड़ने पर किनारे crop होते हैं। Object-position तस्वीर का कौन-सा भाग दिखाना है, उसे नियंत्रित करता है।

तस्वीरों के ऊपर after pseudo-element से dark gradient overlay बनाया गया है। Pseudo-element HTML में अलग tag जोड़े बिना सजावटी layer बनाता है। Gradient का गहरा हिस्सा text के पीछे है, इसलिए सफेद heading तस्वीर पर आसानी से पढ़ी जाती है। Hero copy को relative position और z index one मिला है। Arrow controls और pager के z index इससे ऊपर रखे गए हैं। Header का z index ten है, इसलिए वह carousel से भी ऊपर रहता है। Heading का clamp font छोटा mobile और बड़ा desktop आकार अपने आप चुनता है।

Carousel की गति CSS keyframes से आती है। Hero fade animation छह सेकंड का loop चलाता है। छह images को zero, one, two, three, four और five seconds के animation delay दिए गए हैं। इस stagger के कारण हर लगभग एक सेकंड पर अगली image दिखती है। आख़िरी keyframes rule हर slide को अपने छोटे समय के लिए visible रखता है और फिर opacity zero करके छिपाता है। Opacity बदलाव fade देता है। CSS has selector radio input की checked state पहचानता है, चुनी slide को रखता है और pager number को highlight करता है। इस तरह manual arrows और numbers बिना JavaScript के काम करते हैं। अगर device की prefers reduced motion setting चालू हो तो autoplay रुक सकता है। यह accessibility का हिस्सा है।

Section space class ऊपर और नीचे padding देती है। Section title बड़ा serif heading है, और section lead परिचय का readable width रखता है। Stats section पर pink, violet और blue gradient है। Stat card में border, सफेद translucent background, shadow और colored top border हैं। Strong tag का बड़ा font संख्या को प्रमुख करता है। इससे institute figures तीन अलग cards की तरह दिखते हैं। ये fixed, dated figures हैं, live counter नहीं।

Feature cards के image को fixed display height और object-fit cover मिलता है। Card hover पर translate y minus six pixels card को ऊपर उठाता है और shadow गहरी होती है। Image थोड़ा scale होती है। Transition इन बदलावों को मुलायम बनाता है। Topic cards में hover और focus visible दोनों के लिए यही विचार है; focus visible keyboard से चलने वाले व्यक्ति को चुने हुए link की पहचान कराता है। Research section में gradient और before after pseudo-elements सजावटी shapes बनाते हैं।

Campus video का frame overflow hidden, border radius और shadow से घिरा है। Video width 100 percent और aspect ratio 16 by 9 है, इसलिए screen के आकार के साथ चौड़ाई बदलती है पर अनुपात बना रहता है। Footer में local footer background image के ऊपर linear gradient है। Gradient text को contrast देता है। Footer sections Bootstrap columns के साथ custom padding, text colors और links से सजते हैं।

Responsive design के लिए अलग-अलग media queries हैं। 1100, 900, 760, 700 और 575 pixel breakpoints के पास navbar, search, hero, cards, video और footer के नियम बदलते हैं। छोटी screen पर menu wrap होता है, search width बढ़ती है, hero text के लिए padding बदलती है और cards एक के नीचे एक आ सकते हैं। इसीलिए desktop वाला layout बस छोटा नहीं होता, बल्कि mobile के लिए फिर से व्यवस्थित होता है।

Styles dot css में बहुत से selectors दूसरी pages, जैसे startup, gallery और topic detail के लिए भी हैं। Home page पर वही CSS असर करती है जिसके selectors उसकी HTML classes से मेल खाते हैं। Stylesheet में कुछ selectors और keyframes एक से अधिक बार हैं; अंतिम look समझाने के लिए CSS का क्रम और cascade बताना ज़रूरी है। कुल मिलाकर CSS रंग, typography, spacing, responsive layout, hover, layering, video आकार और carousel movement नियंत्रित करती है। HTML सामग्री देता है; CSS तय करती है कि वही सामग्री सामने कैसी दिखे। धन्यवाद।
